# Insurance Claimants Attorney Representation Prediction

A machine learning classification project designed to predict whether an insurance claimant will hire an attorney (ATTORNEY), comparing Logistic Regression and Decision Tree models evaluated with confusion matrices, classification reports, and ROC-AUC metrics.

## 📌 Project Overview

Legal representation impacts the resolution duration and financial payout of personal injury claims. This project analyzes demographic and accident-level characteristics from claimants.csv to classify whether a claimant is represented by legal counsel.
